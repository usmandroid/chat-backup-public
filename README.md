# ChatGPT Backup Extension

Save your ChatGPT conversations as Markdown or HTML files for backup. Works on Chrome and Firefox.

## Installation (Development)

1. Download or clone this repository.
2. In Chrome, go to `chrome://extensions/` and enable Developer mode.
3. Click "Load unpacked" and select this folder.
4. In Firefox, go to `about:debugging#/runtime/this-firefox` and load the manifest.json or folder.

## Usage

1. Open https://chat.openai.com and log in.
2. Click the extension icon in the toolbar.
3. Use the popup to save the current conversation as Markdown or HTML.

## Publishing

See `Publish.md` for a step-by-step guide to publishing this extension on the Chrome Web Store.
